## 1. Prompt Optimization Checklist (per feature, W1–W7)

Run for each of the 11 upstream flags before sign-off:

- [ ] **Token cost review** — pull per-case input/output tokens from the latest run log (`ai/eval/results/runs/`); flag any feature whose composed prompt stack exceeds budget agreed with Nivin; trim feature-prompt verbosity before touching the shared stack.
- [ ] **Over-refusal review** — re-read outputs for guardrail-adjacent *legitimate* cases; a decline where a partial answer was possible violates the "decline the clause, complete the remainder" rule (`guardrails.md`). Add dataset cases for any over-refusal found.
- [ ] **Tone drift review** — sample 3 outputs per feature side-by-side; check for cheerleading, hedging filler, template-speak, register mismatch between features (student-facing vs executive).
- [ ] **Format conformance** — JSON features produce bare JSON in 100% of runs; word caps hold.
- [ ] **Optimization notes updated** — each prompt file's Notes section reflects what iteration actually changed and why.

## 2. End-to-End Testing Plan

1. **Cross-feature regression suite** — `ai/eval/datasets/w8_e2e_regression.jsonl` re-tests the highest-risk guardrail case from every feature area (injection, fabrication, role-boundary, decision-forcing, format) using per-case `prompt` overrides against the *final* prompt versions. Run: `npm run test:feature -- w8_final_qa --force`.
2. **Shared-stack gate** — any shared prompt change during W8 re-runs `w1_system_prompt` AND `w8_final_qa` before acceptance.
3. **Full re-run** — all 12 feature datasets green on the production model at final prompt versions; run logs archived, reports regenerated with `--report`.
4. **Judge pass** — W6/W7 narrative outputs re-checked through `w6_summary_validation`.
5. **Cost baseline** — record per-feature cost totals from final runs as the production cost baseline handed to Nivin.
